description: AI Mode Exporter의 로컬 인쇄 미리보기에서 Google AI 모드의 선택한 질문과 답변을 PDF로 만드세요.
---

AI Mode Exporter의 PDF 미리보기에서 선택한 질문과 답변을 읽기 쉬운 문서로 저장하거나 인쇄할 수 있습니다.

아직 설치하지 않았다면 [Chrome에 AI Mode Exporter를 설치](/ko/guide/install-and-troubleshoot/)하세요.

## 질문과 답변 선택하기

1. [Google AI 모드](https://www.google.com/search?udm=50)를 열고 질문한 다음 답변이 완료될 때까지 기다립니다. 입력창 위의 **계속하기…**를 클릭하고 저장할 질문과 답변을 선택합니다.
2. 오른쪽 아래의 **계속할 플랫폼** 메뉴를 열고 **다른 이름으로 저장**, **PDF…** 순으로 선택합니다. 선택한 내용의 로컬 인쇄 미리보기가 열립니다.
3. 미리보기를 불러오면 Chrome 인쇄 대화상자가 자동으로 열립니다. 대화상자가 열리지 않거나 닫았다면 미리보기 오른쪽 위의 **인쇄 / PDF로 저장**을 클릭하세요. 인쇄 대화상자에서 대상을 **PDF로 저장**으로 선택한 다음 **저장**을 클릭합니다.

   ![Chrome 인쇄 대화상자에서 대상이 PDF로 저장으로 선택되어 있고 오른쪽 아래에 저장 버튼이 표시됩니다](/images/chrome-print-dialog.webp)

![AI Mode Exporter의 다른 이름으로 저장 메뉴](/images/save-as.webp)

![인쇄 또는 PDF 저장 버튼이 있는 로컬 미리보기](/images/export-pdf.webp)

인쇄 미리보기에서 불러온 이미지와 표는 저장한 PDF에 포함됩니다. 저장하기 전에 이미지를 모두 불러왔고 내용이 완전한지 미리보기에서 확인하세요.
