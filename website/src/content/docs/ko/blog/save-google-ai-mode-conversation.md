AI Mode Exporter를 사용하면 Google AI 모드 대화에서 선택한 질문과 답변을 기기에 저장할 수 있습니다. Markdown 파일로 다운로드하거나 인쇄 미리보기에서 PDF로 저장하세요.

아직 설치하지 않았다면 [Chrome에 AI Mode Exporter를 설치](/ko/guide/install-and-troubleshoot/)하세요.

## 질문과 답변 선택하기

1. [Google AI 모드](https://www.google.com/search?udm=50)를 열고 질문한 다음 답변이 완료될 때까지 기다립니다. 입력창 위의 **계속하기…**를 클릭하고 저장할 질문과 답변을 선택합니다.
2. 오른쪽 아래의 **계속할 플랫폼** 메뉴를 열고 **다른 이름으로 저장**, **Markdown** 순으로 선택합니다. 선택한 내용이 담긴 `.md` 파일이 다운로드됩니다.
3. 오른쪽 아래의 **계속할 플랫폼** 메뉴를 열고 **다른 이름으로 저장**, **PDF…** 순으로 선택합니다. 선택한 내용의 로컬 인쇄 미리보기가 열립니다. 여기서 **인쇄 / PDF로 저장**를 클릭합니다. Chrome 인쇄 대화상자에서 대상에 **PDF로 저장**을 선택한 다음 **저장**을 클릭합니다.

![AI Mode Exporter의 다른 이름으로 저장 메뉴](/images/save-as.webp)

텍스트만 클립보드에 복사하려면 **계속할 플랫폼** 메뉴에서 **복사**를 선택하세요. 선택한 대화가 Markdown 형식으로 복사됩니다.

## 이미지와 표 미리보기

답변에서 지원되는 이미지와 이미지 갤러리, 표가 내보내기에 포함됩니다. 내보내기 전에 **답변 표시**를 눌러 내용을 확인하세요.

![AI Mode Exporter 대화상자에서 이미지 갤러리와 텍스트가 포함된 펼쳐진 답변](/images/support-images.webp)
