AI Mode Exporter を使うと、Google AI モードの会話から選択した質問と回答を端末に保存できます。Markdown ファイルとしてダウンロードするか、印刷プレビューから PDF として保存できます。

まだの場合は、[Chrome に AI Mode Exporter をインストール](/ja/guide/install-and-troubleshoot/)してください。

## 質問と回答を選択する

1. [Google AI モード](https://www.google.com/search?udm=50)を開いて質問し、回答が完了するまで待ちます。入力欄の上にある **続ける…** をクリックし、保存する質問と回答を選びます。
2. 右下の **続ける場所** メニューを開き、**名前を付けて保存**、**Markdown** の順に選択します。選択した内容を含む `.md` ファイルがダウンロードされます。
3. 右下の **続ける場所** メニューを開き、**名前を付けて保存**、**PDF…** の順に選択します。選択した内容のローカル印刷プレビューが開きます。そこで **印刷 / PDF として保存** をクリックします。Chrome の印刷ダイアログで送信先に **PDF に保存** を選び、**保存** をクリックします。

![AI Mode Exporter の「名前を付けて保存」メニュー](/images/save-as.webp)

テキストをクリップボードにコピーするだけの場合は、**続ける場所** メニューの **コピー** を選びます。選択した会話が Markdown 形式でコピーされます。
