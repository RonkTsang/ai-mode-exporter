---
title: Quick start
description: Run the extension and its documentation locally.
---

From the project root, run `pnpm install` and `pnpm dev`. Load
`.output/chrome-mv3-dev` as an unpacked extension from the browser's extension
management page.

In a second terminal, run `pnpm dev:website`. Open
[localhost:4321](http://localhost:4321/) to see the development preview of the
extension's Shadow DOM UI.
