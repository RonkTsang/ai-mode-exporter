---
title: 如何将 Google AI 模式回答保存为 Markdown
description: 在 Chrome 中将 Google AI 模式的回答或整段对话下载为 Markdown（.md）文件，或把选中的问答复制到剪贴板。
---

用 AI Mode Exporter 可以将 Google AI 模式问答保存为 Markdown（`.md`）文件，之后可以用文本编辑器修改，或导入支持 Markdown 的笔记应用。

## 下载 Markdown 文件

1. [安装 AI Mode Exporter](/zh-cn/guide/install-and-troubleshoot/#从源代码安装)，打开 [Google AI 模式](https://www.google.com/search?udm=50)对话并等待回答完成。
2. 点击输入框上方的**继续对话…**，勾选要保留的问答。只想保存一条回答时，只勾选对应问答。要保存整段对话，点击**全选**。
3. 点击右下角的**在其他平台继续**，选择**另存为 → Markdown**。
4. 在 Chrome 的下载记录中找到 `.md` 文件。如果 Chrome 询问保存位置，选择文件夹并确认。

![另存为子菜单中的 Markdown 下载选项](/images/save-as.webp)

## Markdown 如何保存图片和表格

表格会保存为 Markdown 表格。受支持的图片会以在线图片链接的形式保存。预览文件时，查看器需要支持 Markdown 表格，并能访问相应的图片地址。

## 将 Markdown 复制到剪贴板

选中问答后，在**在其他平台继续**菜单中点击**复制**，再将 Markdown 文本粘贴到编辑器。

如果需要可打印的文档，请查看[如何将 Google AI 模式回答保存为 PDF](/zh-cn/blog/save-google-ai-mode-as-pdf/)。[「另存为」教程](/zh-cn/blog/save-google-ai-mode-conversation/)介绍了两种格式。
