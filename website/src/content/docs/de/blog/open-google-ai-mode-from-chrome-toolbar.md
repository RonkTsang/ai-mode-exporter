---
title: Google AI Mode über die Chrome-Symbolleiste öffnen
description: Hefte AI Mode Exporter in Chrome auf dem Desktop an, um Google AI Mode von jeder Webseite aus zu fragen, mehrzeilige Prompts zu schreiben oder einen geöffneten AI-Mode-Chat direkt über das Popup fortzusetzen.
---

AI Mode Exporter fügt deiner Chrome-Symbolleiste ein kompaktes Suchfeld hinzu, mit dem du von jeder Webseite aus eine Unterhaltung in Google Search AI Mode starten kannst, ohne deinen aktuellen Lesefluss zu unterbrechen. Deine Frage wird in einem neuen AI-Mode-Tab geöffnet, während dein aktueller Tab unverändert bleibt.

## Erweiterung an die Chrome-Symbolleiste anheften

Standardmäßig blendet Chrome neu installierte Erweiterungen im Menü **Erweiterungen** aus. Wenn du AI Mode Exporter anheftest, ist das Suchfeld immer nur einen Klick entfernt:

1. [Installiere AI Mode Exporter in Chrome auf dem Desktop](/de/guide/install-and-troubleshoot/), falls noch nicht geschehen.
2. Klicke oben rechts in der Symbolleiste auf das **Erweiterungen**-Symbol von Chrome (das Puzzleteil).
3. Klicke neben **AI Mode Exporter** auf das Pin-Symbol, damit das Symbol dauerhaft in deiner Symbolleiste sichtbar bleibt.

## Google AI Mode von jeder Seite aus fragen

1. Klicke in der Symbolleiste auf das angeheftete Symbol von **AI Mode Exporter**. Das Eingabefeld **AI Mode fragen** erhält automatisch den Fokus, sodass du sofort lostippen kannst.
2. Gib deine Frage ein – zum Beispiel: *„Was kann ich an einem regnerischen Wochenende in Taipeh ohne Auto unternehmen?“*
3. Drücke **Enter** oder klicke auf das Suchsymbol, um deine Frage in einem neuen Google-AI-Mode-Tab zu öffnen.

![Das angeheftete Symbol von AI Mode Exporter öffnet ein Popup mit dem Suchfeld „AI Mode fragen“](/images/toolbar-popup.webp)

:::tip[Mehrzeilige Fragen schreiben]
Drücke unter macOS **Cmd + Enter** oder unter Windows und Linux **Strg + Enter**, um eine neue Zeile einzufügen, ohne die Frage abzuschicken. Das Eingabefeld vergrößert sich beim Tippen automatisch.
:::

## Geöffneten AI-Mode-Chat über das Popup fortsetzen oder speichern

Wenn du dich bereits auf einem Google-AI-Mode-Tab befindest, erscheint im Popup der Symbolleiste unterhalb des Suchfelds zusätzlich die Schaltfläche **Chat fortsetzen…**.

![Auf einem AI-Mode-Tab zeigt das Erweiterungs-Popup die Option „Chat fortsetzen…“ an](/images/toolbar-popup-continue.webp)

Warte, bis die Antwort fertig ist, und klicke auf **Chat fortsetzen…**. Es öffnet sich der Auswahldialog, in dem du folgende Möglichkeiten hast:

- [Die ausgewählten Gesprächsrunden in Gemini](/de/blog/continue-google-ai-mode-in-gemini/) oder [ChatGPT](/de/blog/continue-google-ai-mode-in-chatgpt/) fortsetzen.
- [Die Unterhaltung als Markdown oder PDF speichern](/de/blog/save-google-ai-mode-conversation/) oder in die Zwischenablage kopieren.

:::note[Integriertes Backup, falls die Schaltfläche auf der Seite verschwindet]
Google aktualisiert gelegentlich das Seitenlayout von AI Mode, wodurch die Schaltfläche **Weiter mit…** auf der Seite vorübergehend ausgeblendet sein kann. In diesem Fall öffnest du über **Chat fortsetzen…** im Popup der Symbolleiste genau denselben Dialog.
:::

## Fehlerbehebung

- **AI Mode wird über die Symbolleiste nicht geladen:** Versuche, [Google AI Mode direkt](https://www.google.com/search?udm=50) im selben Chrome-Profil zu öffnen, und folge gegebenenfalls den Anweisungen zur Google-Anmeldung oder Bestätigung.
- **„Chat fortsetzen…“ wird nicht angezeigt:** Stelle sicher, dass du dich auf einem aktiven Google-AI-Mode-Tab (`www.google.com`) befindest, und lade den Tab nach dem Installieren, Aktualisieren oder erneuten Aktivieren der Erweiterung neu.

Wenn sich AI Mode direkt öffnen lässt, das Popup in der Symbolleiste aber weiterhin nicht funktioniert, wirf einen Blick in die [Installations- und Fehlerbehebungsanleitung](/de/guide/install-and-troubleshoot/) oder [kontaktiere den Entwickler](/de/support/).
