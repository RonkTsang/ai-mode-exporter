---
title: 如何將 Google AI 模式對話另存為 Markdown 或 PDF
description: 了解如何使用 AI Mode Exporter，將 Google AI 模式中選取的問題與回答另存為 Markdown 檔案或 PDF。
---

AI Mode Exporter 可將 Google AI 模式對話中選取的問題與回答儲存到裝置。你可以下載 Markdown 檔案，或在列印預覽中另存為 PDF。

如果尚未安裝，請先[在 Chrome 安裝 AI Mode Exporter](/zh-tw/guide/install-and-troubleshoot/)。

## 選取問題與回答

1. 開啟 [Google AI 模式](https://www.google.com/search?udm=50)並提出問題，等待回答完成。點選輸入框上方的**繼續對話…**，再選取要儲存的問題與回答。
2. 開啟右下角的**在其他平台繼續**選單，依序選擇**另存新檔**和**Markdown**。瀏覽器會下載包含所選內容的 `.md` 檔案。
3. 開啟右下角的**在其他平台繼續**選單，依序選擇**另存新檔**和**PDF…**。AI Mode Exporter 會開啟所選內容的本機列印預覽。點選**列印 / 另存為 PDF**，在 Chrome 列印對話方塊中將目的地設為**另存為 PDF**，再點選**儲存**。

![AI Mode Exporter 的「另存新檔」選單](/images/save-as.webp)

若只想將文字複製到剪貼簿，請在**在其他平台繼續**選單中選擇**複製**。系統會以 Markdown 格式複製所選對話。

## 預覽圖片與表格

支援的回答圖片（包括圖片集）與表格會一併匯出。點選**展開回答**即可預覽內容。

![AI Mode Exporter 對話框中展開的回答，包含圖片集與文字內容](/images/support-images.webp)
