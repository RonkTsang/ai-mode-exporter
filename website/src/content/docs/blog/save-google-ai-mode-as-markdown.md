---
title: How to save Google AI Mode answers as Markdown
description: Download a Google AI Mode answer or conversation as a Markdown (.md) file in Chrome, or copy selected questions and answers to your clipboard.
---

Use AI Mode Exporter to save Google AI Mode questions and answers as a Markdown (`.md`) file. Open the file in a text editor to revise it, or import it into a notes app that supports Markdown.

## Download a Markdown file from Google AI Mode

1. [Install AI Mode Exporter](/guide/install-and-troubleshoot/#install-from-source), open your conversation in [Google AI Mode](https://www.google.com/search?udm=50), and wait for the answer to finish.
2. Click **Continue in…** above the AI Mode input. Select the questions and answers to keep. For a single answer, leave only its turn checked. Use **Select all** to export the full conversation.
3. Open **Continue in** at the bottom right, then select **Save as → Markdown**.
4. Find the `.md` file in Chrome’s downloads. If Chrome asks where to save it, choose a folder and confirm.

![The Save as submenu shows Markdown as a download option](/images/save-as.webp)

## Copy Markdown to the clipboard

With your turns selected, choose **Copy** from the **Continue in** menu, then paste the Markdown into your editor.

For a printable copy, see [how to save Google AI Mode answers as a PDF](/blog/save-google-ai-mode-as-pdf/). The [Save as guide](/blog/save-google-ai-mode-conversation/) covers both export options.
