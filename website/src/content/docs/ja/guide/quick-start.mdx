AI Mode Exporter を使うと、Google 検索の AI モードで 3 つのことができます。選んだ質問と回答を **Gemini や ChatGPT で続ける**、**Markdown や PDF として保存・コピーする**、そしてどのタブからでも **Chrome ツールバーから新しい AI モード検索を始める**ことができます。

:::note[始める前に]
- **拡張機能をインストール**：まだの場合は、デスクトップ版 Chrome に [AI Mode Exporter をソースからインストール](/ja/guide/install-and-troubleshoot/#ソースからインストールする)してください。
- **事前にサインイン**：[Gemini](https://gemini.google.com/) または [ChatGPT](https://chatgpt.com/) で会話を続ける予定がある場合は、あらかじめログインしておくとスムーズです。
:::

## Gemini または ChatGPT で会話を続ける

<Steps>

1. **Google AI モードで質問する**

   [Google AI モード](https://www.google.com/search?udm=50)を開いて質問し、回答の生成が終わるまで待ちます。完了すると、入力欄の上に**続ける…**ボタンが表示されます。

   ![AI モードの入力欄の上にある会話を続けるボタン](/images/onboarding-entry.webp)

2. **引き継ぐやり取りを選ぶ**

   **続ける…**をクリックして選択ダイアログを開きます。引き継ぎたい質問と回答にチェックを入れ（または**すべて選択**をクリック）、右下の**続ける場所**メニューから **Gemini** または **ChatGPT** を選びます。

   ![質問と回答を選択し、引き継ぎ先を選ぶ画面](/images/onboarding-selection.webp)

3. **下書きを確認して送信する**

   選択した内容が下書きとしてセットされた新しい会話が開きます（**自動送信はされません**）。取り込まれた内容を確認し、続けて聞きたい質問を入力してから送信してください。

   ![選択した会話が Markdown 添付ファイルとして追加された Gemini の下書き](/images/onboarding-gemini.webp)

</Steps>

:::tip[各プラットフォームでの取り込み方]
Gemini では選択した会話が Markdown ファイルとして添付されます。ChatGPT では入力欄にテキストが直接挿入されます（内容が長い場合はテキスト添付ファイルになることがあります）。
:::

## 会話を保存・コピーする

別のサービスへ移動せず、手元に回答を残すこともできます。選択ダイアログ右下の同じ**続ける場所**メニューから、ローカルへエクスポートできます。

- **コピー**：選択したやり取りを Markdown 形式でクリップボードにコピーします。
- [**名前を付けて保存 → Markdown**](/ja/blog/save-google-ai-mode-as-markdown/)：メモアプリなどでそのまま使える `.md` ファイルをダウンロードします。
- [**名前を付けて保存 → PDF…**](/ja/blog/save-google-ai-mode-as-pdf/)：見やすいローカルプレビューを開き、印刷または PDF として保存できます。

![Markdown と PDF のオプションを表示する名前を付けて保存サブメニュー](/images/save-as.webp)

## Chrome ツールバーのポップアップを使う

拡張機能を Chrome ツールバーに固定しておくと、2 つの便利な機能をワンクリックで使えます。

1. Chrome ツールバー右上の**拡張機能**アイコン（パズルピース）をクリックします。
2. **AI Mode Exporter** の横にあるピンアイコンをクリックしてツールバーに固定します。

### どのページからでも AI モードに質問する

どのページを開いていても、ツールバーの **AI Mode Exporter** アイコンをクリックし、**AI Mode に質問**欄に質問を入力して **Enter** キー（または検索アイコン）を押します。現在開いているページを残したまま、新しいタブで Google AI モードの検索が始まります。

![Chrome ツールバーに固定した AI Mode Exporter と、検索欄を表示したポップアップ](/images/toolbar-popup.webp)

### ページ内のボタンが見つからないときの代替手順

:::tip[ページ内に「続ける…」ボタンが表示されない場合]
Google のページ更新により、ページ内のボタンが一時的に表示されなくなることがあります。その場合はツールバーのポップアップから開けます。
:::

回答が完了した Google AI モードのタブを開いた状態で、ツールバーの **AI Mode Exporter** アイコンをクリックし、**このチャットを続ける…**を選択してください。まったく同じ選択ダイアログが開き、Gemini / ChatGPT への引き継ぎや保存を行えます。

![Google AI モードで AI Mode Exporter のポップアップを開き、このチャットを続けるボタンを表示](/images/toolbar-popup-continue.webp)
